# FrammingApp

🇧🇷 Aplicativo Android (Java) de catálogo e acompanhamento de filmes, no estilo Letterboxd combinado com compra de ingresso: telas de filmes populares/em breve, diário de filmes assistidos (DiaryActivity), críticas de usuário, listas personalizadas de filmes, favoritos, cadastro de ingresso com confirmação de cartão salvo, e edição de perfil. Consome uma API própria hospedada no Render (framming-api.onrender.com) via Retrofit/OkHttp -- não é só um app de UI sobre uma API pronta de terceiro.

🇬🇧 Android app (Java) for cataloging and tracking movies -- a Letterboxd-style diary/reviews app combined with ticket purchasing: popular/upcoming movie screens, a watched-movies diary (DiaryActivity), user reviews, custom movie lists, favorites, ticket checkout with saved-card confirmation, and profile editing. Talks to its own backend hosted on Render (framming-api.onrender.com) via Retrofit/OkHttp -- not just a UI shell over a ready-made third-party API.

**Stack:** Java, Android SDK, Retrofit/OkHttp, backend próprio (Render)
**Contexto:** provável projeto da época técnica (ETEC, 2021-2023).
